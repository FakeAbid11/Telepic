Why Telepic

A gallery that stays yours.

Everything you expect from a modern photo app, with the cloud replaced by a channel you control.

Local-first library

Reads photos, videos and GIFs directly from MediaStore as one paged, newest-first timeline. Thumbnails load first; originals stay on the device unless you ask for a cloud copy.

Telegram as backup

Backups go to a private channel you own, through TDLib. WorkManager runs uploads under a real network constraint and a foreground notification.

Content, not filenames

Streaming SHA-256 identity means the same bytes are never uploaded twice, even if they reach the library through different files or names.

Private by design

No ads, analytics or account with Telepic. Photo GPS is read on-device for the map and is not uploaded. Optional app lock and screenshot protection are built in.

Made for browsing

Day-grouped timeline, albums, a full-screen viewer, EXIF details, a map of geotagged media, and an explicit “Save to device” restore flow.

Open source

Kotlin and Jetpack Compose, with the backup state machine and cloud mapping covered by a JVM test suite. Apache-2.0 licensed.

The flow

Three steps, one private channel.

  1. Connect Telegram

    Sign in to your own account. Telepic discovers or creates a private backup channel and verifies your posting rights.

  2. Choose what to back up

    Back up the whole library or only selected folders. Hiding videos or GIFs in the grid never silently changes what gets backed up.

  3. Let it run

    The queue survives restarts, retries transient failures, and confirms every upload against Telegram before marking it backed up. Restore originals on demand.

Project status

Debug milestone, honest about validation.

The app is code-complete and CI-tested, but live Telegram, MediaStore write/delete, video playback, map rendering and the device-credential prompt still need real-device validation. The README lists the exact gaps.
